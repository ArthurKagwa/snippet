Help with code and design

Fix a bug, improve a card style, or make the docs clearer. For bigger changes, open an issue first so we can talk it through.

  1. Fork the repo and create a branch from main. Follow the setup guide.
  2. Keep changes small. Use theme tokens for colours and one component per file. Keep files under 300 lines.
  3. Run flutter analyze and flutter test, then open a pull request. Add screenshots for visual changes.
